# scry

Pick a folder of StarCraft II replays and scry shows them as a searchable library: builds, units, skills, fights, chat.
Open a game to see a timeline, a replay on a minimap, build orders and your own notes.
Use it to find the games worth cutting into a highlights reel.

Runs entirely in your browser at https://fiffu.github.io/scry. Replays are never uploaded.

Run it locally: `make deps && make dev`, then open http://127.0.0.1:8000. How it works: [DESIGN.md](DESIGN.md).
